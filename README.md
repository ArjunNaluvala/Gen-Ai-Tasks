# Gen AI Internship – Python Logic Building Tasks

This repository contains the tasks completed during the initial days of the **Gen AI Internship**.
The focus of these tasks was to improve **Python programming fundamentals and logical problem solving**.

## Objective

The goal of these exercises was to strengthen Python basics and build logical thinking required for real-world programming and AI related tasks.

## Topics Covered

* Basic Python programming
* Logical problem solving
* Working with loops and conditions
* Functions in Python
* List and dictionary operations


## Learning Outcome

* Improved problem solving skills using Python
* Better understanding of Python syntax and logic building
* Practice with writing clean and structured code
